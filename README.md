
#  Mudabbir – Personal Finance Dashboard

**Manage Your Money Smartly**

Mudabbir is a modern personal finance dashboard designed to help users monitor and organize their financial activities through a clean, organized, and user-friendly interface.

The dashboard provides an overview of income, expenses, budgets, transactions, monthly bills, accounts, and payment methods in one place.

##  Features

- **Financial Overview:** Display current balance, total income, and expenses.
- **Recent Transactions:** View transaction history, categories, dates, amounts, and payment statuses.
- **Budget Management:** Track monthly budgets, spending, and remaining balances.
- **Income & Expenses:** Visual comparison between income and expenses.
- **Monthly Bills:** Overview of recurring bills such as electricity, internet, phone, and subscriptions.
- **Account Summary:** Display bank accounts, savings accounts, and credit card balances.
- **Payment Methods:** Display different payment methods, including Visa, Mastercard, and PayPal.
- **Recent Activities:** Keep track of recent financial activities and updates.
- **Quick Actions:** Shortcuts for sending money, adding funds, paying bills, and investments.

##  Technologies Used

- CSS3
- Font Awesome Icons

##  Design

- Arabic interface with Right-to-Left (RTL) layout.
- Modern dashboard layout.
- Organized financial cards and sections.
